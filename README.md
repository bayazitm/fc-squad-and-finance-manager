# fc-squad-and-finance-manager
The primary objective of this project is to develop a data-driven management and decision support system that integrates the athletic squad planning of a modern professional football club with its administrative and financial obligations under a single enterprise relational database architecture.

In traditional management approaches, administrative staff, the finance department, and the technical team operate using disparate, disconnected data sources. This fragmentation leads to data inconsistencies, inaccurate budget forecasts, and delayed strategic decisions. The proposed system aims to eliminate these inefficiencies by unifying all operational club units within a shared, centralized database schema.
